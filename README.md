# Integral Website

This repository is for reporting issues with the integralcollective.io website 
— typos, broken links, outdated information, or anything that needs attention.

Open an issue to report a problem. The trustee reviews and resolves all 
website issues directly. This is not a governance space — issues are resolved 
at trustee discretion without consensus process.

For project contributions, see [integral-devguide](../integral-devguide).

---

## Future Scope: Node Network Web Presence

As real nodes emerge, each will require its own local web presence — a way 
for node communities to engage with their own Integral instance, communicate 
locally, and connect back to the broader network.

The architecture for this layer should reflect the same principles as the 
economic system itself: decentralized, resilient, locally sovereign, and 
federated through shared protocols rather than shared infrastructure. A node 
website is not just a local brochure — it is potentially part of how a 
community engages with its own system, how local activity surfaces into 
network-wide awareness, and how the federation becomes legible to itself 
and to the outside world.

Holochain is the leading candidate framework for this layer. Its agent-centric 
peer-to-peer architecture eliminates central hosting dependencies, means each 
node hosts its own data, and keeps the network functional even if parts of it 
go offline. This aligns directly with Integral's federation model and its 
resilience requirements. Holochain is already identified in the development 
guide as a reference technology for the broader infrastructure layer.

Questions that will need to be worked through as nodes emerge:

- What is the relationship between a node's local site and integralcollective.io?
- How does local community engagement surface into network-wide awareness?
- What is standardized across all node sites versus locally determined?
- How does the FRS feedback loop connect to public-facing node communication?
- How are node sites discovered and verified as part of the legitimate network?
- What happens to a node's web presence if the node dissolves or goes dormant?

This repository will expand to address those questions when the time comes. 
For now it serves only as a feedback channel for the main site.
